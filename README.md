# UnePDF

Ferramentas de PDF para Windows, **100% locais**: os arquivos nunca saem do seu computador.

> Projeto em desenvolvimento. A primeira versão vai trazer a ferramenta "Unir PDFs".

## Rodando pelo código-fonte

Requer Python 3.11 ou superior.

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements-dev.txt
py -m pytest
```
